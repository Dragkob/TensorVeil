#

TensorVeil is an open-source security research framework for exploring tensor steganography in machine learning models. It automates embedding arbitrary payloads into the mantissa bits of model weights and provides tooling to study payload reconstruction during model deserialization, helping researchers understand and evaluate ML supply-chain risks.
